# Read-Me
Click on the top-right green button called 'Code', and click 'Download ZIP'.

## Getting Started
1) Download and install XAMPP: https://www.apachefriends.org/
2) After installation, extract the 'news_layout' folder to the htdocs folder (C:\xampp\htdocs)
3) Open the XAMPP Control Panel.
4) Click 'Start' for both Apache and MySQL. 
- Click 'Admin' under the MySQL row, this opens phpMyAdmin in your browser.
5) In phpMyAdmin, click 'New' on the left sidebar and create a database named 'newslayout'.
6) Click on the 'newslayout' database, go to the Import tab.
- Click 'Choose File', select 'newslayout.sql' from the db_file folder.
- Click 'Import'.
7) Run the shortcut named 'Click me to run!'. This opens the project in your browser!
